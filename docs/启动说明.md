# Lagoon 启动说明

**版本：v2.2.0 · 打包日期：2026-09-27**

Lagoon = macOS 客户端（本包内的 `Lagoon.app`）+ 本地服务端（Swift，Hummingbird）+ Postgres（Docker）。三者的关系：

```
Lagoon.app ──HTTP──> LagoonServer (127.0.0.1:8080) ──> Postgres (:5433, Docker)
                                          │
                                          └──IMAP/SMTP──> QQ 邮箱 / Gmail
```

## 一、这台 Mac 已经装好（无需重复操作）

如果你是在打包来源的这台机器上使用，一切都在运行中：

| 组件 | 状态 | 位置 |
|---|---|---|
| Lagoon.app | `dist/Lagoon.app`，双击即用 | 本包内同款 |
| 服务端 | launchd 常驻自启（`com.lagoon.email.server`） | `~/Library/LaunchAgents/com.lagoon.email.server.plist` |
| Postgres | Docker 容器 `lagoon-postgres` | `docker compose up -d` 可拉起 |
| 数据库迁移 | 018/019 已应用 | — |

日常启动顺序：**开机后什么都不用做**——服务端自启，双击 `Lagoon.app` 即可。
如果服务端没起来（比如 Docker 没开导致同步报 unreachable）：

```bash
cd /Users/panbo/Code/Demos/lagoon-email
docker compose up -d                          # 先起 Postgres
launchctl kickstart -k gui/$(id -u)/com.lagoon.email.server
```

日志：`~/Library/Logs/Lagoon/server.log`（server.error.log 是错误通道）。

## 二、换一台新 Mac 的完整清单

1. **装 Postgres 并起库**（Docker Desktop/OrbStack）：
   ```bash
   cd <仓库目录>
   docker compose up -d
   ```
2. **配置环境**：`cp .env.example .env`，填入 `LAGOON_TOKEN_KEY`（`openssl rand -base64 32` 生成）等；QQ 授权码在 App 内首次连接时输入，不进 .env。
3. **迁移数据库**：`bash scripts/db-migrate.sh`
4. **编译并安装服务端常驻代理**：`bash scripts/install-server-agent.sh`（自动 release 构建 + launchd 自启）
5. **装 App**：把本包内 `Lagoon.app` 拖进「应用程序」，打开（首次右键 → 打开，绕过未公证提示；或 `xattr -dr com.apple.quarantine /Applications/Lagoon.app`）
6. 打开 App → QQ 邮箱标签 → 输入邮箱 + 16 位授权码（QQ 邮箱 → 设置 → 账户 → 开启 IMAP/SMTP 并生成）

## 三、故障速查

| 症状 | 处置 |
|---|---|
| App 显示 unreachable / 同步红点 | Postgres 没起或服务端没起，见上方两条命令 |
| App 打不开提示未公证 | `xattr -dr com.apple.quarantine <app 路径>`（本包为临时签名，本地使用无碍） |
| 撤销/归档报错 | 先看 server.error.log；远端失败时本地状态不会变 |
| 换端口/地址 | server 读 `.env` 的 `LAGOON_SERVER_HOST/PORT`；App 读 `LAGOON_SERVER_URL`（默认 `http://127.0.0.1:8080`） |
