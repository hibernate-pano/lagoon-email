> ⚠️ **本节初稿的归因是错的，已按探针证据推翻重写。** 初稿写「4 个提交没有一个针对 CI 报的那 15 条 Tests 警告」「大概率仍会红」，并把根因归给工具链差异。**两者都不成立**，证据见下。

**三级证据链（本次新增第 2、3 条为决定性）**：

1. **CI 侧**：`gh run list --limit 8` 显示 main 最近 4 次全部 `completed failure`，均挂在 `== Warning gate ==` 阶段 `❌ 15–17 unapproved compiler warning(s)`，**从未跑到 `== Test ==`**。最近一次是 `13551b2`（2026-10-06）。
2. **git 侧**：`main...origin/main [ahead 4]` —— `aff827c` / `589206d` / `4b7f7a1` / `fac65b6` **从未推送，CI 一次都没跑过它们**。CI 报的 17 条，验的是 `13551b2` 的代码。
3. **逐条对账：那 17 条在 HEAD 已全部消失**（`aff827c` 顺手修掉了）：

| CI 报的警告（`13551b2`） | 条数 | HEAD 现状 | 谁修的 |
|---|---|---|---|
| `ColumnWidthStore.swift:231/245` `result of call to 'settle' is unused` | 2（**Sources/**） | `settle(...)` 返回值丢弃模式 = **0 条** | `aff827c`：`settle(...)` + `return widths[column]` → `return settle(...)` |
| `Tests/` `no 'async' operations occur within 'await'`（DeleteBulk 129/312、Purge 123/184/196、Restore 147、Sender 77、StackCount 81、SentListing 83） | 11 | `await (db\|conn\|raw).(read\|write)` = **0 条**（`13551b2` 时 DeleteBulkTests 单独就有 2 条） | `aff827c`：删掉多余的 `await` |
| `SentListingTests.swift:237` `let provider was never used` | 1 | 全 `Tests/` 未使用 `let provider` = **0 处** | `aff827c`：删掉那行 |
| `SentListingTests.swift:400:32 / 409:32` `result of call to 'write' is unused` | 2 | `SentListingTests` 已无 `conn.write` 调用 | `aff827c`：重写该测试 |
| 小计 | **17** | **0** | |

4. **决定性探针：这不是工具链差异。** 用本机 Swift **6.4** 单独编译一段含同样模式的代码：

```swift
struct DB { func read(_ b: () -> Void) { b() }; func write<T>(_ b: () -> T) -> T { b() } }
func g() async { let db = DB(); await db.read { }; _ = await db.write { 1 }; try? await db.read { } }
```

6.4 照报：`no 'async' operations occur within 'await' expression [#UnnecessaryEffectMarker]` ×3 与 `no calls to throwing functions occur within 'try' expression [#UnnecessaryEffectMarker]`。**6.4 与 6.1.2 在这两类上行为一致**，所以「本地绿」的原因是**代码里没有这些模式了**，不是「6.4 看不见」。

**更正后的结论**：CI 红与本地绿不矛盾——**两者验的不是同一份代码**。`docs/基线体检-2026-10-08.md:236` 把根因写成「本地 Swift 6.4 / CI Swift 6.1.2 诊断集不同」，这个归因**是错的**（本次探针推翻），真正原因是 CI 停在 `13551b2`。

**验证（2026-10-09 13:21 落袋）**：推送 7 个提交（`13551b2..6d6e606`）后，CI run `37887452442` 在 **Swift 6.1.2** 上跑完全部 `run-all-tests.sh`：
`864 tests, 2 skipped, 0 failures`（CI 上 91.6s），末行 `ALL CHECKS PASSED`，`conclusion=success`，用时 05:12:17 → 05:21:09（8m52s，与 v3.1.0 那次 8m40s 同量级）。
这同时证明：
（1）P1-1 的更正判断正确 —— 那 17 条确实已被 `aff827c` 修掉，warning gate 在 6.1.2 下一次过；
（2）10-08 报告的「工具链差异」归因彻底作废 —— 同一个 6.1.2，旧代码红、新代码绿；
