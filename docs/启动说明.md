# Lagoon 启动说明

**版本：v3.0.1 · 打包日期：2026-09-30**

从这一版起，Lagoon 是**单文件应用**：服务端（Swift/Hummingbird）和 SQLite 存储全部内嵌在 `Lagoon.app` 进程里，数据只落在这台 Mac 上。

```
Lagoon.app（一个进程）
  ├─ SwiftUI 客户端
  ├─ LagoonRuntime（内嵌服务端，127.0.0.1）
  │     ├─ Sync Engine（每账号一条 IMAP/SMTP 连接）
  │     └─ SQLite（Application Support/Lagoon/lagoon.sqlite，WAL）
  └─ AI 网关 ──> MiniMax（仅 AI 摘要/草稿的文本出机）
```

## 一、日常使用

- **打开 `Lagoon.app` 即可**，没有 Docker、没有 launchd、没有 .env、没有迁移脚本。
- 数据位置：`~/Library/Application Support/Lagoon/lagoon.sqlite`（含 -wal/-shm）。备份 = 拷走这一个文件（先退出 App）。
- 密钥位置：Keychain。首次启动自动生成 AES 密钥（`lagoon.tokenKey`）和本机 API token（`lagoon.apiTokenSecret`）。
- AI 配置：首次启动会自动从旧版仓库 `.env`（launchd 时代）迁移 `LLM_PROVIDER_*`、`LAGOON_BUDGET_USD_PER_MONTH` 到 Keychain，无需重新输入。

## 二、换一台新 Mac

1. 把 `Lagoon.app` 拖进「应用程序」，打开（临时签名的包首次需右键 → 打开，或 `xattr -dr com.apple.quarantine /Applications/Lagoon.app`）。
2. 连接页输入邮箱 + 16 位授权码（QQ 邮箱 → 设置 → 账户 → 开启 IMAP/SMTP 并生成）。
3. 想要 AI 摘要/草稿：新机器没有旧 `.env` 可迁移，需要把 MiniMax key 写进内嵌配置——当前临时入口是设置环境变量后启动，或把 key 存入 Keychain 服务 `lagoon.envJSON`（JSON 字典）。

## 三、从 v2 升级（这台机器）

1. 卸载旧 launchd 常驻代理（否则它会继续从旧仓库拉起旧服务端、占用 8080）：
   ```bash
   launchctl bootout gui/$(id -u)/com.lagoon.email.server
   rm ~/Library/LaunchAgents/com.lagoon.email.server.plist
   ```
2. 停掉并移除 Docker Postgres：
   ```bash
   docker rm -f lagoon-postgres 2>/dev/null || true
   ```
3. 打开新的 `Lagoon.app`。**旧 Postgres 里的数据不迁移**：邮件本体都在服务商那里，会自动重新同步；置顶/归档规则/聚合规则需要重建；`ai_actions` 审计历史从零开始（time-saved 读数会重置）。

## 四、故障速查

| 症状 | 处置 |
|---|---|
| 启动页显示「启动失败」 | 8080 被旧服务端占用 → 执行上面第三节的 launchctl 卸载；App 会自动尝试 8081–8090 |
| 同步红点 / needsReconnect | 邮箱授权码失效，重新 Connect；远端失败时本地状态不会变 |
| AI 功能 503 | 内嵌 AI 配置缺失（见第二节第 3 条） |
| App 打不开提示未公证 | `xattr -dr com.apple.quarantine <app 路径>` |
| 想彻底重来 | 退出 App，删除 `~/Library/Application Support/Lagoon/`，重开（Keychain 密钥可保留） |

## 五、当前版本包含（v3.0.1）

- v2.2.0 全部功能：Briefing 分诊 Feed、一键退订、白名单自动归档 + 推荐、会话/发件人/平铺三档归集透镜、用户自定义聚合、档案柜、清扫、废纸篓删除、全可撤销、time-saved 统计
- **新：零依赖单进程架构**——内嵌 SQLite（WAL），测试不再需要 Docker（每测试独立临时库，永远可跑）
- **新：密钥全部进 Keychain**，磁盘上不再有含密钥的 .env

安全须知：本包为**临时签名**（ad-hoc），仅限本机/可信机器使用；对外分发需要 Developer ID 签名 + 公证。邮件数据不出本机（AI 调用会把相关文本发给你配置的模型服务商）。
