# 三栏拖曳手感 —— 量化验收规格（交付总监定义）

> 这份文档定义"顺滑"的可测量标准。没有量化，QA 无法验收，工程师只能凭感觉调。
> 这些数值是 macOS 平台惯例 + Apple HIG 的取值，不是拍脑袋。

## 一、手柄（拖曳命中区）

| 项 | 值 | 理由 |
|---|---|---|
| 可视分隔线宽度 | 1pt | 视觉上是一条线，不该是一根棍 |
| **命中区宽度** | **10pt** | HIG 与 Finder/Mail 的分隔线命中区都是 8–12pt。低于 8pt 在 Retina 上很难捕捉 |
| 命中区是否跨越相邻栏 | 是，向两侧各溢出到相邻栏内 4.5pt | 让"瞄准"有容错，不必精确落在 1pt 线上 |
| 拖曳中命中区是否变宽 | 否，宽度恒定；只改颜色 | 命中区变化会让用户误判边界在哪 |
| 光标 | 水平双向 resize（`.colResize` / `NSCursor.resizeLeftRight`） | 标准信号，用户不需要学习 |
| hover 时手柄视觉 | 颜色加深（不要加阴影或放大） | 克制；放大会让布局抖动 |

## 二、拖曳过程

| 项 | 规格 | 理由 |
|---|---|---|
| **拖曳期间动画** | **必须全部禁用** | 这是"顺滑"的头号开关。任何 `.animation`/`withAnimation` 会让宽度追赶手指，产生橡皮筋滞后感 |
| 宽度更新方式 | 与视图解耦，不走 SwiftUI 状态驱动的整树重算 | 见架构文档的性能章节 |
| 分隔线拖动阈值 | `minimumDistance: 0`（按下即开始） | 拖分隔线不需要"确认意图"；设阈值会让用户以为没抓到 |
| 首帧延迟 | 0（按下即响应） | 同上 |
| 拖曳中命中区域外 | 指针仍被捕获（capture），拖出窗口也不丢失拖曳 | 否则快速拖到边缘会"脱手" |

## 三、橡皮筋阻尼（边界）

| 项 | 规格 |
|---|---|
| 越界时是否阻尼 | 是 |
| 阻尼曲线 | 越界量 `over` 映射为实际位移 `over / (1 + over/150)`，即前 10pt 几乎跟手，之后快速衰减 |
| 阻尼上限 | 实际位移不超过 40pt（再拖也不动） |
| 松手回弹 | 回到硬边界（min 或 max），带动画 |
| 回弹动画时长 | 约 0.15s（快到几乎察觉不到，快才不烦） |

## 四、补偿规则（加权弹性）

| 项 | 规格 |
|---|---|
| 参与补偿的栏 | 被拖栏**之外的全部**栏 |
| 权重 | 侧边栏 1.0 /列表 2.0 / 阅读器 3.0（阅读器权重最大 = 窗口变窄时优先牺牲它） |
| 补偿方向 | 所有栏**同向**响应（拖宽列表 → 侧边栏与阅读器**同时**变窄），符合直觉 |
| 是否重新分配已触界的栏 | 是：某栏触界后立刻固定，其剩余需求按权重**重新分摊**给仍可动的栏 |
| 空间不足时 | 按优先级依次突破 `softMin`，**不得溢出、不得为负** |

## 五、边界与降级

| 窗口宽度 | 行为 |
|---|---|
| ≥ 832pt（正常） | 三栏都可用，加权补偿正常工作 |
| 720–832pt | 阅读器可低于 `min` 但不低于 `softMin` |
| < 720pt | 超出产品承诺范围；内容裁剪，**不崩溃、不出现负宽度** |

## 六、持久化

| 项 | 规格 |
|---|---|
| 存什么 | 三栏的 `min`/`ideal`/`max` 宽度（拖定的实际值） |
| 存哪 | `@AppStorage`，key前缀 `lagoon.column.` |
| 何时写 | **拖曳结束时（mouseup）写一次**，不是每帧写（每帧写会拖慢拖曳） |
| 何时读 | 布局初始化时 |
| 跨显示器 | 以"该显示器可用工作区宽度"校验：恢复时若当前屏幕容不下存档宽度，按比例缩放到合法区间 |
| 双击重置 | 回到 `ideal`，并立即持久化 |

## 七、无障碍（macOS 硬要求，P0）

| 项 | 规格 |
|---|---|
| 手柄角色 | `.adjustable` 或明确的可调整元素 |
| 上下箭头 | 每次调整 16pt（一个"步进"） |
| PageUp/PageDown | 每次调整 64pt |
| Home/End | 直接到`min` / `max` |
| `accessibilityValue` | 播报当前宽度，如"340 点"，随调整更新 |
| `accessibilityLabel` | 明确是哪个分隔线，如"调整邮件列表宽度" |
| VoiceOver 可聚焦 | 手柄必须可聚焦，不只是鼠标可用 |

## 八、双击

| 项 | 规格 |
|---|---|
| 触发 | 双击任一手柄 |
| 行为 | 三栏全部回到 `ideal` |
| 视觉反馈 | 立即生效（不要动画，double-click 的语义就是"重置"） |
| 持久化 | 是，立即写入 |
