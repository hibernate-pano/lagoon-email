# 竞品研究：QQ邮箱 × 网易邮箱大师（废纸篓 / 归档 / 批量操作）

> 研究日期：2026-10-05
> 目的：为 Lagoon（macOS SwiftUI 邮件客户端）补齐「废纸篓管理」「归档恢复」提供交互参照
> **证据分级说明**：
> - 🟢 **官方一手文档**（腾讯 / 网易官方帮助中心、官方更新日志）
> - 🟡 **可靠二手**（太平洋电脑网、百度经验等实操截图教程，描述具体可验证）
> - 🔴 **不可信**（大量 AI 生成的下载站/百科农场内容，本次调研中已剔除，不作为结论依据）

---

## 0. 先说三个最关键的结论

1. **QQ邮箱个人版没有 Gmail 式「归档（Archive）」。** 网上说的「已归档」是用户自己新建的普通文件夹。腾讯真正有「邮件归档」的是**企业邮增值服务 + 审计员权限**，跟个人版无关。
2. **网易邮箱大师（网页版 / 桌面端 / 移动端）全部没有「归档」按钮。** 官方帮助文档里，邮件的唯一去向是「移动到某个文件夹」。它用「文件夹 + 标签 + 红旗 + 置顶」四件套替代归档。
3. **两家产品都把「删除」拆成两段：删除（进已删除）→ 彻底删除（不可逆）**，且**已删除文件夹的自动清理期限不同且都明确公示**：QQ邮箱 30 天，网易 7 天。这个差异本身就是很好的产品设计参考。

## 1. QQ邮箱

### 1.0 平台形态澄清（重要）

| 形态 | 是否存在 | 说明 |
|---|---|---|
| 网页版 | ✅ | `mail.qq.com`（老版）／`wx.mail.qq.com`（2025 新版）。2025-02 升级为 **QQ邮箱 7.0**，默认**双分栏**（左功能区 + 右邮件+预览），可切三分栏 🟡 |

| iOS / Android | ✅ | App Store / 应用宝，腾讯官方 |

### 1.1 废纸篓 / 已删除

#### 删除 vs 彻底删除（官方原文）🟢

来源：`https://service.mail.qq.com/detail?search=已删除`（QQ邮箱帮助系统）

> **我怎样删除邮件？**
> 删除邮件，有两种处理方法：
> 1. 在邮件列表区点击邮件前面的复选框，会出现一个打勾的标记；
> 2. 点击邮件列表区最上方的**「删除」**，即可将打勾的邮件删除到**「已删除」**邮件夹中。
>
> **彻底删除邮件**
> 注意！使用彻底删除的方法将**不再把邮件删除到「已删除」邮件夹中，而是直接永久删除并且无法恢复**！选择需要彻底删除的邮件，直接点击**「彻底删除」**即可。

**关键交互细节（可直接抄）：**
- 两个按钮**在工具栏上并列且物理相邻**：左边第一个是「删除」，左边第二个是「彻底删除」🟡 —— 用户不需要去「更多」菜单里找危险操作
- 危险按钮紧邻常用按钮，是**「相邻即风险」**的经典做法：降低误点距离的同时，语义上仍需用户主动区分
- 彻底删除**有二次确认弹窗**，文案是「是否确定删除该邮件，彻底删除后该邮件无法恢复」，按钮为「确定」🟡

#### 保留期限与容量提示（官方原文）🟢

> **我的邮件会被系统自动删除吗？**
> 一般情况下，邮件不会自动删除。但是如果您将邮件放在"已删除"邮件夹，系统会**30 天自动清除一次**"已删除"邮件夹中的信件。另外，系统会 30 天自动清除一次"垃圾邮件"邮件夹中的信件。
> **请注意：千万不要把您有用的信件放在"已删除"文件夹中。**

> **我的"已删除"邮件夹中的邮件会占用邮箱空间吗？**
> 会占用。为了节省空间，系统对存在于"已删除"中 **30 天以上**的邮件会被自动删除，所以，请您不要将有用的邮件放在"已删除"邮件夹，以免造成损失。

**设计要点：**
- ✅ **明确告知「删了还占空间」** —— 这是国内邮箱几乎都会说的一句话，因为用户最大的误解就是「删了＝空间释放了」
- ✅ **明确给出 30 天数字**，并且**官方帮助页面用警告语气重复了三遍**（30 天自动清除 / 占空间 / 千万不要放有用的信）
- ✅ 官网帮助系统条目直接叫「我的'已删除'邮件夹中的邮件会占用邮箱空间吗？」—— 把用户的真实疑问做成 FAQ 标题 🟢

#### 清空废纸篓

- 🟡 网页版：进入左侧「已删除」→ 点顶部「清空」/「清空已删除邮件」→ 弹窗确认
- 🟡 App 端：进入「已删除」→ 右上角「编辑」→ 底部「清空」→ 再确认
- **没有找到官方对「清空废纸篓」确认弹窗完整文案的记载**。第三方教程只说「在弹出的确认框中，点击确定完成永久删除」🟡

#### 废纸篓里能不能预览 / 恢复

- ✅ **能预览**：已进入「已删除」文件夹的邮件仍可正常打开阅读 🟢（附件夹文档明确：「已删除文件夹和垃圾箱中的邮件附件**不会**纳入附件夹」—— 说明邮件本体和附件在已删除状态下仍完整存在，只是被排除在附件索引之外 🟢）
- ✅ **能恢复**：路径是「进入已删除 → 勾选邮件 → 点上方『移动到』→ 选『收件箱』」🟡
- ❌ **没有专门的「恢复」按钮**。恢复动作复用「移动到」，语义上是"移动"而不是"恢复"
  > 💡 **这是一个明显的 UX 缺口，也是 Lagoon 的机会点**：在废纸篓场景下，「移动到收件箱」的心智负担远高于一个直白的「恢复」。

- 🟡 **撤销（Undo）**：删除后顶部会出现「已删除 撤销」的提示条，**几秒内**可点击撤销；「不管是普通删除还是彻底删除，都可以撤销」。提示条消失后无法撤销 🟡
  > 💡 这是「给危险操作一个时间窗」的成熟设计，成本低、收益高。

#### 会员增值：彻底删除也能捞回来

- 🟢 超级会员/钻石会员可用 **「自助查询」→「删信查询」**，检索 30 天内**已彻底删除**的邮件（普通用户只有 7 天窗口的垃圾箱找回）
  - 入口：网页版 `设置 → 账户 → 自助查询 → 误删邮件查询/删信查询`
  - 提交后结果通常 **24 小时内**返回
- 🟡 垃圾箱另有「恢复邮件 / 找回邮件」入口：左侧「垃圾箱」→ 顶部「更多操作」→「恢复邮件」，可扫描近 **7 天**内被清空的邮件，勾选后「恢复到收件箱」

### 1.2 归档 / 已归档

#### 结论：**个人版没有归档功能** 🔴→🟡

经过多轮检索，证据链如下：

| 说法 | 判定 |
|---|---|
| 「QQ邮箱有归档按钮」 | 🟡 大量教程言之凿凿说「勾选邮件 → 点上方『归档』按钮 → 进入归档文件夹」 |
| 实际情况 | 🟡 **该「归档」实为用户自建的普通文件夹**。腾讯官方帮助系统里**没有「归档」功能的任何问答**，只有「标签」和「文件夹和标签」的完整文档 🟢 |
| 官方仅有的「归档」 | 🟢 是**读信页的「归档至」按钮** —— 语义是「把这个联系人/主题的往来邮件**全部**归到一个文件夹」，弹窗里有「同时归档收件箱里的历史邮件」勾选项 🟡。**这不是 Gmail 式归档，是"归档到指定文件夹 + 可选连带历史"** |
| 真正的系统级归档 | 🟢 **腾讯企业邮增值服务**，入口在左侧菜单底部**「邮件归档」**，**仅"审计员"角色可见**，需微信扫码授权，可按时间/发件人/主题/附件类型高级检索，查到后可预览、导出 PDF、重新投递（仅限企业域内） |

**给 Lagoon 的判断：**
> QQ邮箱用「**标签**」而不是「归档」来做"让收件箱清爽"这件事。标签支持一封邮件挂多个、可自定义颜色、可排序、**有未读时自动排到最上**、可由收信规则自动打标 🟢。这套东西的功能覆盖度 ≈ Gmail 的归档 + 标签，但**用户入口是分散的**（标签在导航栏、归档至在读信页）。

#### 归档 vs 删除的 UI 区分

- 🟢 **QQ邮箱把两者彻底区分为不同文件夹**：删除 → 系统文件夹「已删除」（带垃圾桶隐喻）；归档至 → 用户文件夹（无特殊图标，彩色标签块）
- 🟡 工具栏上「删除」是垃圾桶图标、「彻底删除」是更重的垃圾桶图标，**没有第三种颜色区分**—— 归档压根不在工具栏上，所以不存在三者并排的辨识负担

#### 取消归档 / 从归档恢复的入口

- 🟡 用户在「已归档」文件夹里勾选邮件 → 点「移动到」→ 选「收件箱」
- 🟡 部分版本在归档文件夹内提供「移回收件箱」/「反归档」按钮
- ❌ **没有 Gmail 那种从搜索结果/详情页一键「移回收件箱」的全局入口**

### 1.3 批量操作

#### 工具栏典型按钮 🟡

勾选邮件后，列表上方出现的一排（从左到右，参考删除/彻底删除的相对位置）：

```
[全选▾] [删除] [彻底删除] [移动到 ▾] [标记为 ▾] [举报垃圾邮件] [...] 更多
```

官方可确认存在的项：
- 🟢「举报」—— 「在邮件列表中勾选需要拒绝的邮件，点击工具栏的『举报』即可」，会把邮件移到垃圾箱并**把发件人加入黑名单**（来源：`kf.qq.com` / `help.mail.qq.com/detail/158/1040`）
- 🟢「移动到」（含「新建文件夹」选项）
- 🟢「标记为」下拉 —— 可新建标签、可打多个标签、可「标记为已读/未读」、可点亮星标
- 🟢「拒收」—— 读信页和工具栏都有，加发件人黑名单
- 🟡「归档」（实为跳转自建文件夹，见上文存疑说明）

#### 全选的两个层级 🟡

- **当前已加载页全选**：列表左上角「全选」复选框
- **全选当前文件夹**：`Alt + A` 🟡
- **筛选后再批量**：先在搜索框设条件（发件人/主题/时间范围）得到筛选结果 → 在结果页勾选 → 批量操作
  > 💡 这就是「**全选当前筛选结果**」的等价实现：**先筛选，后全选**。Lagoon 可以直接照抄这个心智模型。

#### 批量操作是否要确认弹窗

- 🟢 **移入「已删除」：不弹确认**（普通删除是低危可逆操作）
- 🟡 **彻底删除：弹确认**，文案「是否确定删除该邮件，彻底删除后该邮件无法恢复」
- 🟡 **批量彻底删除 / 清空废纸篓：弹确认**

> 💡 **可抄的分级原则**：可逆操作不打断，不可逆操作一律弹窗但**必须说明不可逆后果**，而不是只问「确定吗？」

### 1.4 排序、筛选、搜索

- 🟢 **搜索入口**：顶部搜索框，支持关键词 / 发件人 / 主题 / 时间范围 / 有无附件等多维组合，检索结果按相关性排序
- 🟢 **搜索可限定在已删除文件夹内进行**（网易也有这个能力，见 2.4；QQ 侧通过高级搜索选项实现）
- 🟡 **筛选**：列表上方提供「按日期、大小、附件有无、是否已读」四维组合筛选，**筛选结果即时刷新且保留历史操作记录**
- 🟢 **收信规则**（替代手动整理的核心能力）：
  - 入口：`设置 → 收信规则 → 新建规则`
  - 条件：发件人包含 / 主题包含 / 正文包含 / 带有附件 / 含超链接 / 是群邮件 / 是订阅邮件
    - ⚠️ 官方明确限制：**不支持正则表达式**，**仅匹配纯文本内容**，**不支持以「我作为收件人时的邮箱地址」为条件** 🟡
  - 动作：移动到文件夹 / 标记为重要 / 标记星标 / 标记已读 / 删除（官方原文警告慎用）
  - 🟡 创建后弹窗：「是否同步应用到历史邮件？」—— **默认要勾选才能把历史邮件也归进去**
  - 🟢 可用规则对历史邮件批量执行

### 1.5 快捷键体系

**官方无障碍帮助页公布的全部快捷键** 🟢（`https://mail.qq.com/zh_CN/htmledition/accesskey_help.html`）：

> 全局：`alt+0` 无障碍说明 · `alt+9` 无障碍版本 · `alt+shift+c` 写邮件 · `alt+shift+i` 读邮件 · `alt+shift+o` 打开设置 · `alt+shift+m` 打开附件夹
> 写信页：`alt+shift+t` 收件人框 · `alt+shift+q` 正文 · `alt+shift+s` 发送
> 读信页：`alt+shift+q` 快速回复 · `alt+shift+g` 回复 · `alt+shift+h` 回复全部 · `alt+shift+j` 转发 · `alt+shift+n` 下一封 · `alt+shift+b` 上一封
> 邮件列表：`alt+shift+n` 下一页 · `alt+shift+b` 上一页

**注意：官方完全没有公布 删除 / 归档 / 移动 / 标记 的快捷键。**

🟡 第三方教程给出的邮件列表键位（未在官方页面验证，可信度较低，仅供参考）：

| 键位 | 动作 |
|---|---|
| `Ctrl + Shift + M` | 新建邮件 |
| `Ctrl + D` | 删除选中邮件 |
| `Ctrl + F` | 当前文件夹内搜索 |
| `Space` | 选中当前行并打开 |
| `Shift + ↑/↓` | 连续多选 |
| `Shift + Click` | 不连续多选 |
| `Alt + F` | 快速过滤 |
| `Alt + A` | 全选当前文件夹所有邮件 |

> ⚠️ **反向发现（对 Lagoon 很有价值）**：QQ邮箱作为国内最主流的邮箱，**其官方快捷键体系是围绕"无障碍"而非"效率"建设的**。`alt+shift+X` 这种组合对普通用户极难上手，实用性远低于 Apple Mail / Outlook 的 `⌘+E 归档` / `Delete 删除` / `⌘⇧U 标为未读` 体系。**这给 Lagoon 一个明确机会：把 macOS 平台惯例键位做对，本身就是差异化。**

### 1.6 已读/未读、星标、标签、文件夹体系

**文件夹体系** 🟢：
- 系统文件夹：收件箱、草稿箱、已发送、**已删除**、垃圾箱、订阅邮件、广告邮件
- 「我的文件夹」：用户自建，支持多级
- 「附件夹」：跨文件夹聚合所有普通附件（**已删除和垃圾箱的附件不纳入** 🟢）
- 「记事本」「中转站」「日历」为并列模块

**标签** 🟢（官方帮助原文）：
- 通过「标记为」下拉框新建标签，**一封邮件可标一个或多个标签**
- 「设置 → 文件夹和标签」中管理：可**设定标签颜色**、**设定导航栏中的顺序**（**有未读时会自动排到最上，此时不受排序影响**）
- 「设置 → 收信规则」中可让新来信自动打标签
- 标签出现在邮件列表中（彩色块），点击标签名可查看该标签下所有邮件；在自建文件夹中点击标签则只看该文件夹内的

**星标** 🟡：点亮邮件标题后的五角星，邮件进入独立的「星标邮件」文件夹

**已读/未读** 🟡：未读加粗显示；工具栏「标记为」可切换；删除时无论已读未读一并处理

**置顶**：❌ **个人版 QQ邮箱网页版没有「置顶邮件」功能**（网易有，见 2.5）

## 2. 网易邮箱大师

### 2.0 平台形态

| 形态 | 是否存在 | 说明 |
|---|---|---|
| 网页版 | ✅ | `mail.163.com` / `mail.126.com`，**三栏式**（左导航 / 中列表 / 右预览）🟡 |
| macOS 原生客户端 | ✅ | 官网提供 **5.0 增强版**（全新界面）与 **4.0 经典版** 🟢（`https://dashi.163.com/`） |
| Windows / Linux | ✅ | 同上 |
| iOS / Android | ✅ | 🟢 |

**Mac 版布局** 🟡：**四栏式原生布局** —— 左侧黑色功能区 → 账号区 → 邮件列表区 → 阅读视窗，针对 Mac 宽屏优化。

> 💡 **对 Lagoon 的意义**：这是本次调研中**唯一一个真正的 macOS 原生邮件客户端竞品**，也是最直接的对标对象。QQ邮箱在 Mac 上根本没有原生产品。

### 2.1 废纸篓 / 已删除

#### 删除 vs 彻底删除（官方原文）🟢

来源：`https://mail.163.com/help/help_mail_16.htm`

> **如何删除邮件？**
> 一旦彻底删除邮件，即意味着永久删除。如果您认为可能还会需要某封邮件，我们建议您将该邮件**存档**，而不是彻底删除。
> **首先**，将邮件移至"已删除邮件"。（您仍可以搜索或找回"已删除邮件"中的邮件。）
> · 打开邮件 · 单击邮件上方的**「删除」**按钮；或在勾选邮件列表中需要删除的邮件，点击列表上方的**「删除」**按钮。
> **然后**，选择**「彻底删除」**。（完成这一步骤后，您将无法还原邮件。）
> **移至"已删除"的邮件会在 7 天后被我们的系统自动删除。**

另一份官方文档（企业邮 Coremail 帮助）补充了「清空」按钮 🟢：

> **彻底删除邮件**：若要删除"已删除"文件夹中的邮件，请打开"已删除"文件夹，选择需要彻底删除的邮件，点击**「彻底删除」**按钮完成；点击**「清空」**按钮将彻底删除"已删除"文件夹中的全部邮件。若要将收件箱中的邮件直接删除，而**不通过删除到"已删除"文件夹的中间过程**，则选择需要删除的邮件，**直接点击「彻底删除」按钮**即可。
> **注意：彻底删除的邮件不可以再还原，因此，请你慎用此项操作。**

**关键交互细节（可直接抄）：**
- 🟢 「清空」按钮与「彻底删除」按钮**并排在已删除文件夹的顶部工具栏**，是**独立的、显眼的、专门为此设计的按钮**，而不是让用户自己全选再点彻底删除
- 🟢 官方文案措辞极其克制且有说服力：**「一旦彻底删除邮件，即意味着永久删除。如果您认为可能还会需要某封邮件，我们建议您将该邮件存档，而不是彻底删除。」** —— 主动劝阻 + 给出替代路径
- 🟢 「移至已删除的邮件**仍可以搜索或找回**」被写进官方帮助 —— 把"可恢复"作为降低用户心理成本的说辞明确传达

#### 保留期限（官方原文）🟢

来源：`https://mail.163.com/html/mail5faq/130520/page/5QQFVP1F00753VB8.htm`

> 系统会自动清空存放在**订阅邮件**文件夹中 **30 天**或以上的邮件，存放在**已删除**、**广告邮件**文件夹中的 **7 天**或以上时间的邮件，以及存放在**垃圾邮件**文件夹中 **1 天**或以上时间的邮件（其他文件夹不受影响）。
> 注：以上文件夹下的邮件一旦被系统清空无法恢复，请您定期整理邮箱中的邮件，以免被清除。

> 💡 **这张表是整份研究里最值得抄的一张表。** 把**每个系统文件夹各自的自动清空期限**公开成一张对照表，并区分「哪些文件夹不受影响」，这让用户能精确判断风险等级。对 Lagoon 的废纸篓：**明示"第 N 天自动永久删除"比只写"30 天内可恢复"诚实得多，也更负责任。**

| 网易文件夹 | 自动清空期限 |
|---|---|
| 收件箱 / 已发送 / 自定义文件夹 | **不受影响** |
| 订阅邮件 | 30 天 |
| 已删除 / 广告邮件 | 7 天 |
| 垃圾邮件 | 1 天 |

#### 客户端 / 会员的额外兜底

- 🟢 会员增值服务「**误删恢复**」：可恢复 **30 天内彻底删除**的邮件。入口：网页版 `自助查询 → 删信查询 → 误删恢复`（另一份文档写 10 天，版本有差异，以 30 天为准）
  - 恢复范围明确列出 4 类：① web 邮箱中被彻底删除的（含系统文件夹、自定义文件夹、邮箱中心）；② web 页面 pop 时未留副本的；③ 客户端（Outlook/Foxmail 等）接收时未留副本的；④ **设置了自动转发且未在本网箱保留副本的，无法恢复**
- 🟢 网易邮箱还有个**「客户端删信」文件夹，可找回 180 天内被删除的邮件**（来源：`mail.163.com/mailmaster/help/10.html` 官方原文）—— 这是一个很特殊的第三层回收站
- 🟢 网易企业邮箱：网页版左侧栏有独立的**「邮件恢复」**按钮

#### 废纸篓里能不能预览 / 恢复

- ✅ **能预览**
- ✅ **能恢复**，三种路径：
  1. 🟡 网页版：左侧「已删除」→ 勾选 → 顶部「移动到」→ 选「收件箱」
  2. 🟡 桌面端：**右键该邮件 → 「移动至」→ 选目标文件夹**；或读信页点三个点 →「移动」
  3. 🟡 移动端：长按邮件 → 右下角「移动至...」→ 选「收件箱」
- ❌ **同样没有专门的「恢复」按钮**，一律走「移动至」

#### 清空废纸篓的确认流程

- 🟢 **手机端有明确的「立即清除」二级流程**：进入个人中心 → 「已删除」选项 → 点「立即清除」→ 选择「彻底删除」🟡
  > 💡 「立即清除」和「彻底删除」是两个动作的组合，而不是一个按钮直接完成。这种**两步式危险操作**（先唤起清理面板，再在面板内选择强度）值得抄。

- 🟡 **桌面端有「智能清理」**（在文件夹内点右上角 `…` →「智能清理」），可设定**时间范围**（如"3 个月前"）或**大小阈值**（如"大于 5MB"）自动筛选并一键删除 🟡
  > 💡 **「智能清理」是废纸篓管理里最值得抄的功能**：不只提供"全选/清空"这种粗暴操作，而是让用户按**条件**清理（时间、体积、发件人）。对一个本地邮件客户端来说，"释放空间"是真实高频诉求——按体积清理比按时间清理更有价值。

### 2.2 归档 / 已归档

#### 结论：**没有归档功能** 🟢

证据（官方帮助文档全量检索）：
- 网易邮箱大师**桌面端使用手册**（`office.163.com/helpCenter/mail/d/1935284039743885313.html`）中，读信详情页顶部操作区完整列举为：**「回复、回复全部、转发、删除、待办、整理、更多」** —— 🟢 **没有「归档」**
- 「整理」的定义是：「对邮件进行『聚合』或『移动』的整理」🟢 —— 归档没有被当成一个独立动作
- 「更多」的定义是：「『作为附件转发』、『标记为未读』、『标为红旗』、『举报垃圾邮件』」🟢 —— 同样没有归档
- 网易移动端使用手册的读信页操作枚举中也没有归档 🟢
- 网易官方帮助中心的 FAQ 分类中，「邮件的查看与整理」分类下只有：搜索不到邮件 / 邮件加载失败 / **批量删除/移动/标记邮件** / 恢复误删的邮件 / 忘记加密文件夹的密码 🟢 —— **没有归档相关条目**

**它用什么替代归档？** 🟢 **「邮件聚合」**：
> 邮件可以按**自定义主题**（如"周报""申请资料"）进行聚合，同一**发件人**（如人力资源部、财务处）的邮件也可以聚合。
> 1. 按收件人聚合：把历史上来自 xx 的全部邮件聚合在一起，方便查看来往邮件。
> 2. 按自定义主题关键词聚合：把内含关键词"周报"的全部邮件聚合在一起。
> 3. **批量移动**：可将邮件批量移动到自定义文件夹中，**并且可以将此设置应用到新邮件中**。

> 💡 **这是与 QQ邮箱「标签」完全不同的思路**：网易选择「**聚合视图**」——不移动邮件本体，而是在读信页把相关邮件折叠成会话线程；把"清理收件箱"这件事交给「批量移动到自定义文件夹」+「来信分类规则」。

#### 归档 vs 删除在 UI 上的区分

- 🟢 **网易的区分方式是「文件夹归属」而非图标/颜色**：
  - 删除 → 系统文件夹「已删除」，在文件夹列表中固定位置、固定垃圾桶隐喻
  - 移动/整理 → 自定义文件夹，在「我的文件夹」区，可自建命名
  - 置顶 → 仍在原文件夹，**置顶到列表顶部**（不进任何文件夹）
  - 待办 → **仍在原文件夹，置顶 + 状态标识**

> 💡 **网易的「置顶」和「待办」是一个非常好的设计**：它们**实现了"让邮件从收件箱列表中凸显出来但完全不离开原位"**的效果 —— 这恰恰是很多产品想做「归档」时真正想要的语义（不是"移走"，而是"降噪但可快速找到"）。Lagoon 的「归档」如果要做得对，可以考虑「收件箱视图内降噪 + 可切换到归档视图」的双视图设计，而不是物理移动。

#### 取消归档 / 恢复入口

- 不适用（无归档）。等价的"取消整理"路径：进目标文件夹 → 勾选 → 「移动至」→ 选回原文件夹（收件箱）

### 2.3 批量操作

#### 工具栏 / 操作条按钮（官方原文）🟢

来源：`https://office.163.com/helpCenter/mail/d/1892504736484700162.html`（智能收信/读信前）

> **2、批量管理**
> 在邮件列表页支持**鼠标 + 键盘快捷键**（如 `shift+鼠标左键`、`ctrl/cmd+鼠标左键`），可以多选邮件进行统一操作：**标为已读/未读、标为红旗/取消红旗、打标签、移动、删除**。
> **点击邮件列表复选框后的箭头可进行全选/不选，一键筛选已读/未读邮件。**
> 支持**鼠标拖动邮件快捷移动**至其他文件夹中。

移动端（官方原文）🟢：
> 读信列表页的快捷操作：删除操作和设置为红旗邮件 —— **向右滑动**，可对选中的邮件"删除"；点击某封邮件右边的红旗标识，可将该封邮件标识为红旗邮件。
> **批量操作"删除"、"标记"、"移动"** —— **长按**某封邮件，可触发"全选"的批量操作，全选后，可对多封邮件进行"删除"、"移动"。

> 💡⭐ **「点击复选框后的箭头可进行全选/不选，一键筛选已读/未读邮件」—— 这是整份研究里最值得直接照搬的一条交互。**
> 一个复选框承担了 4 个功能：① 选中当前页全部；② 取消全选；③ 只看未读；④ 只看已读。
> 用户不需要在"全选"和"筛选"之间来回切换，**"全选"和"筛选未读"这两个高频需求在同一个控件上被统一了**。Lagoon 的复选框应该考虑做成这个形态（点击=全选/取消，长按或点击箭头=筛选菜单）。

其他批量能力 🟢：
- 「**全标已读**」：当列表中有未读邮件时会出现「全标已读」按钮，一键把当前文件夹所有未读标为已读
- 「**全标已读**」的移动端入口：向下滑动列表，顶部出现「标记已读」，旁边有「多选」
- 「**批量作为附件转发**」：多选后点「作为附件转发」，一键把选中邮件作为附件加到写信页
  - ⚠️ 限制：**该功能在「按主题聚合」模式下不可用** 🟢
- 「**批量置顶 / 取消置顶**」：多选后一键操作
- 「**导入 eml**」：系统文件夹或自定义文件夹右键 →「导入邮件」，支持多选 eml 文件；也可直接把本地 eml 文件**拖拽**到文件夹
- 「**邮件批量删除（按条件）**」：右键左侧账号或文件夹 →「邮件批量删除」→ 设定时间范围（近 30 天 / 自定义日期）和邮件大小 → 确认后彻底删除匹配邮件 🟡

#### 全选是怎么做的

- 🟢 **复选框 + 点击箭头**（全选 / 不选 / 筛选已读 / 筛选未读）—— 见上
- 🟢 **键盘：`Ctrl/Cmd + 鼠标左键` 不连续多选，`Shift + 鼠标左键` 连续多选**
- 🟡 桌面端：`Ctrl + A` 全选
- 🟢 **`全标已读` 是唯一有明确"作用范围 = 整个文件夹"的批量操作**（不是"当前已加载"）
- 🟢 **搜索结果页支持「删除全部」** —— 对**当前条件下搜索到的全部邮件**（而非已加载的那一页）执行删除
  > 💡⭐ **这是「全选当前筛选结果而非全选已加载」的正解**。不通过"选中 N 封邮件"来实现，而是提供一个**作用于整个结果集的动作**。Lagoon 若要做这个，正确姿势是给筛选结果一个**集合级操作**（"删除全部匹配项"），并在文案里明确范围，而不是假装全选。

#### 批量操作是否有确认弹窗

- 🟢 **移入「已删除」：不弹确认**（与 QQ邮箱一致）
- 🟢 **彻底删除 / 清空 / 智能清理 / 批量删除：弹确认**
- 🟢 智能清理的确认面板会**明确列出即将影响的范围**（时间范围 + 大小阈值条件）
- 🟡 未找到弹窗完整文案的官方记载

### 2.4 排序、筛选、搜索（官方原文，最详细的一份）🟢

#### 搜索三级递进

1. **本地搜索**（默认优先）
   - 入口：文件夹列表页顶部导航栏「搜索」按钮
   - 关键词位置可选：**全部 / 主题 / 发件人 / 收件人**
   - **记录搜索历史**，方便复用
2. **云端搜索**（自动衔接）
   - 本地搜索完成后**自动发起云端搜索**，按提示选择是否展示云端结果
   - 逻辑：**默认优先使用本地搜索，如果发现本地结果搜索不全，可再尝试使用【云端搜索】**
3. **高级搜索**（入口在搜索框右侧）
   - 条件：目标文件夹、主题、正文、发件人、收件人、时间、**是否红旗邮件**、是否包含附件、**标签筛选**
   - 「**满足以上任一条件**」（与/或，默认同时满足所有）
   - 收件人/发件人输入框**自动联想通讯录联系人**
   - **支持按附件名称搜索邮件**

**搜索结果页二次筛选** 🟢：可按 **文件夹 / 发件人 / 时间范围 / 有无附件 / 阅读状态（自己已读、自己未读）** 继续收窄。

#### 搜索已删除的邮件（官方原文）🟢

来源：`https://mail.163.com/mailhelp/find.htm`

> **想要搜索一封已删除的邮件可以吗？**
> **只要这封邮件没有被彻底删除就可以找到**，步骤如下：
> 1. 点击邮箱页面上方的「邮件高级搜索」链接；
> 2. 在「请输入要搜索的字或词条」旁边空白处填写关键词；
> 3. 在「选择要搜索的文件夹」旁边选择**「已删除」文件夹**；
> 4. 选择好所有的搜索条件后，点击「开始搜索」按钮。

> 💡⭐ **「已删除」是一个可被搜索的文件夹** —— 这一条设计非常精妙。它把废纸篓从"墓地"变成了"可检索缓冲区"：你不必记得删了哪封，只需要记得关键词。同时它也让"删除是可逆的"这个承诺变得**可验证**，而不只是一句口号。**强烈建议 Lagoon 采纳：废纸篓内的邮件必须能被搜索命中。**

### 2.5 置顶 / 红旗 / 待办（网易最有特色的部分）🟢

**置顶** 🟢（官方原文）：
> 在邮件列表**右键**可以选择将邮件**置顶/取消置顶**。
> 在读信页**顶部工具栏**【置顶/取消置顶】图标对邮件操作置顶/取消置顶。
> 在邮件列表中选中多封邮件，支持一键【置顶】、【取消置顶】。
> **注意：非聚合模式下，一个文件夹下最多同时置顶 20 封邮件。**

> 💡⭐ **「一个文件夹最多同时置顶 20 封」这个硬性上限，是防止"置顶退化成第二个收件箱"的成熟设计。** 置顶一旦无限制，用户就会把所有邮件都置顶，置顶的意义归零。设上限 + 到顶后给出提示，是非常克制的做法。Lagoon 做置顶时应该抄这个上限。

**红旗（= 星标）** 🟢：
- 读信页【更多】→「标为红旗」
- 邮件列表**右键**可标/取消
- 批量：「标为红旗/取消红旗」
- 独立的「**所有红旗**」文件夹（移动端左上角 `≡` →「所有红旗」）
- 高级搜索支持「**是否红旗邮件**」作为条件

**待办（网易独有的"邮件转任务"）** 🟢：
> 待办：对邮件进行"待处理"设置，可设置**提醒处理的时间**。**已设置待办的邮件将在列表中置顶显示**，处理后可将该邮件的状态标识为"完成待办"。

> 💡 **「待办 = 置顶 + 状态机 + 提醒时间」的三元组合**，比单纯的星标强得多。移动端还有独立的「待办」文件夹聚合所有待办邮件；会员还有「最近查看」文件夹。

**紧急邮件标识** 🟢：对方发信时标记为紧急的，邮件列表会展示紧急标识

### 2.7 邮件备注（很值得抄的小功能）🟢

## 4. 可直接抄的具体设计（10 条）

> 每条都标注了来源与「为什么值得抄」。

### ① 复选框箭头 = 全选 + 筛选已读/未读（四合一控件）
- **来源**：网易官方文档 🟢 ——「点击邮件列表复选框后的箭头可进行全选/不选，一键筛选已读/未读邮件」
- **抄什么**：列表头复选框点击 = 选中/取消本页全部；旁边小箭头 = 下拉菜单（全部 / 未读 / 已读 / 取消全选）
- **为什么**：把「全选」和「筛选未读」两个最高频需求收敛进**同一个控件**。用户不需要在"选择模式"和"筛选模式"之间来回切换。实现成本极低，体验提升立竿见影。

### ② 废纸篓必须可被搜索命中
- **来源**：网易官方文档 🟢 ——「只要这封邮件没有被彻底删除就可以找到」
- **抄什么**：全局搜索的作用域包含「废纸篓 / 已删除」；结果里被删邮件要有明确的状态标识
- **为什么**：这把废纸篓从"墓地"变成"可检索缓冲区"，让"删除是可逆的"从一句口号变成**可验证的事实**。同时它极大降低了用户不敢删的心理负担 —— 这会反过来提高归档/删除功能的整体使用率。

### ③ 明示每个系统文件夹的自动清空期限
- **来源**：网易官方文档 🟢 —— 订阅邮件 30 天 / 已删除 7 天 / 垃圾邮件 1 天 / 其他文件夹不受影响
- **抄什么**：在废纸篓列表页顶部（或文件夹属性里）明确写：**"废纸篓中的邮件将在 N 天后自动永久删除"**，最好带上"哪些文件夹不受影响"的完整说明
- **为什么**：国内邮箱的通行做法是隐瞒或模糊（QQ邮箱要在帮助系统 FAQ 里才能找到）。桌面客户端是本地存储，**用户对"数据会不会丢"极度敏感**。主动告知反而是建立信任的最快方式。

### ④ 「清空废纸篓」必须是独立按钮，不是"全选 + 彻底删除"
- **来源**：网易官方文档 🟢 ——「点击『清空』按钮将彻底删除『已删除』文件夹中的全部邮件」
- **抄什么**：进入废纸篓后，工具栏出现专用的「清空废纸篓」按钮，与「彻底删除」并排
- **为什么**：要求用户"先全选再点彻底删除"是把两步风险操作拼在一起，用户会本能地犹豫。给一个专用按钮，是承认"这是个独立的高频动作"。

### ⑤ 危险操作的两段式：先唤起面板，再在面板内选强度
- **来源**：网易移动端「立即清除」→「彻底删除」🟡
- **抄什么**：「清空废纸篓」→ 弹出清理面板（列出将影响多少封 / 多少体积 / 涉及哪些筛选条件）→ 在面板内选择"永久删除"或"仅移出"→ 才真正执行
- **为什么**：把"决定"和"执行"分开，让用户在按下最终按钮前有一次完整的认知机会。比一个"确定吗？"的弹窗有效得多。

### ⑥ 按条件智能清理（时间 / 体积 / 发件人），而不是只有"全选"
- **来源**：网易「智能清理」🟡 + 「邮件批量删除」（近 30 天 / 自定义日期 / 邮件大小）🟡
- **抄什么**：清理面板提供筛选维度 —— 时间范围、体积阈值、发件人、是否带附件；系统先筛选出匹配项并展示「将清理 N 封 / 释放 X MB」，再让用户确认
- **为什么**：本地客户端的废纸篓清理，**真实动机是"释放磁盘空间"**而不是"我不要这些邮件"。按体积清理比按时间清理更贴合动机。这是废纸篓管理里最容易做出差异化的功能。

### ⑦ 删除后 5~10 秒的「撤销」提示条
- **来源**：QQ邮箱「已删除 撤销」🟡
- **抄什么**：删除后在原位置（或列表底部）出现一条 toast：`已删除 3 封邮件  [撤销]`，带倒计时，条消失后不可撤销
- **为什么**：给危险操作一个低成本的时间窗。**注意：QQ邮箱声称"彻底删除也能撤销"** —— 这个设计更激进，但也意味着"彻底删除"其实不是真的不可逆。若要采用，Lagoon 需明确定位：是"彻底删除真的不可逆"（更安全，符合用户预期），还是"永远可撤销"（更宽容，但与"永久删除"的语义冲突）。**建议：彻底删除不可撤销，但普通删除一定有撤销。**

### ⑧ 置顶数量上限，并在触顶时明确提示
- **来源**：网易官方文档 🟢 ——「非聚合模式下，一个文件夹下最多同时置顶 20 封邮件」
- **抄什么**：置顶操作有硬上限；触顶时提示"本文件夹最多置顶 N 封，请先取消部分置顶"
- **为什么**：无上限的置顶会退化成第二个收件箱，置顶的意义归零。**上限是防止功能退化的必要约束**，且给了用户明确的取舍依据。

### ⑨ 删除与移动的按钮相邻但语义分离
- **来源**：QQ邮箱官方 —— 「删除」与「彻底删除」在工具栏上并列相邻 🟡
- **抄什么**：`删除（垃圾桶）` 和 `彻底删除（垃圾桶+划线/加重）` 物理相邻，前者直接执行，后者弹确认；两者视觉上必须能一眼区分
- **为什么**：把危险操作放在常用操作旁边（而不是藏进「更多」菜单），既降低"要找"的心智负担，又通过二次确认兜底。同时"相邻即风险"的空间关系让用户对危险度有直觉感知。

### ⑩ 危险操作文案：先说不可逆的后果，再给替代路径
- **来源**：网易官方原文 🟢 ——「一旦彻底删除邮件，即意味着永久删除。如果您认为可能还会需要某封邮件，我们建议您将该邮件存档，而不是彻底删除。」
- **抄什么**：确认弹窗的正文不是「确定删除吗？」，而是：
  > **将永久删除 12 封邮件，此操作无法撤销。**
  > 如果只是想整理收件箱，可以考虑使用「归档」。
  > `[归档]  [永久删除]`
- **为什么**：把「确认弹窗」从"拦截"变成"建议"。**在确认弹窗里同时提供替代方案**，是防误删最有效的设计 —— 用户本来就想删，但看到还有一条不那么损失的路，往往会重新判断。

**补充两条低成本高价值的：**
- **邮件备注 + 备注可搜索**（网易 🟢）：本地客户端无需服务端支持即可实现，搜索时能命中备注内容
- **数字键 1~9 直跳第 N 封邮件**（网易 🟢）：比逐个 `↓` 导航快得多，配合 `P`/`N` 形成完整键位组
