## §A 死链与假控件（用户已决策）

- **决策（用户，2026-10-21）**：**暂时移除死链，界面不留假按钮**。
- **复核结论（2026-10-22 · 本地化与文案域）**：报告的**根因描述有误，但结论成立**。
  - `supportAddress` 里**不是**脱敏占位符——那是一个真实的 21 字符邮箱地址。
    `{{EMAIL_…}}` 是**本仓库工具链输出里的脱敏字样**，源文件里没有这个串
    （逐字节 `od -c` 与字符级核对确认过）。台账上一版把它当成"没替换的占位符"
    是被脱敏输出误导了。
  - 真正的死因是**域名没注册**：`lagoon.email` 在 IANA 的 RDAP 注册局查询里
    两次都是 404（`rdap.identitydigital.services`、`rdap.org`），NS 记录
    NXDOMAIN，HTTPS 不通。⚠️ 本机 DNS 被沙箱接管（`198.18.0.0/15` 是
    sinkhole，`apple.com` 也解析到 198.18.x.x），**`dig` 的结果不能当证据**；
    `whois lagoon.email` 打印的是 `.email` **顶级域**的注册局记录，不是域名本身。
  - 还有第三处没人提：`AboutSheet.swift:90` **没有用** `LagoonHelp.siteURL`，
    自己又写死了一遍 `https://lagoon.email`——所以光改常量不够。
- **修法（已落地）**：
  1. 支持渠道与官网都改成**配置**：从 app 的 `Info.plist` 读
     `LagoonSupportEmail` / `LagoonWebsiteURL`，**没配置就没有链接**
     （`supportAddress` / `feedbackMailto` / `siteURL` / `supportMailto` /
     `bannerMailto` 全部可空）。仓库里不再有邮箱，也不再有指向未注册域名的链接。
  2. `AboutSheet` 的「发送反馈」「访问官网」**只在有链接时渲染**；横幅的「帮助」
     本来就挂在 `if let helpURL = banner.helpURL` 上，`bannerMailto` 返回 `nil`
     时按钮自动消失——**8 处调用点一行没改**。
  3. 守卫测试：`Tests/LagoonTests/DeadLinkTests.swift`（5 条）。
  4. **要恢复渠道**：在 `Support/Info.plist` 里加 `LagoonSupportEmail`
     （和/或 `LagoonWebsiteURL`）。**那个文件不是本域的**，请中枢指派。
- **验收**：`grep -rn '{{EMAIL_' Sources/` → 0 命中；
  `grep -rn 'lagoon.email' Sources/` → 只剩 `EmbeddedServer.swift:475` 的
  LaunchAgent 文件名 `com.lagoon.email.server.plist`（bundle id，不是链接）。
  死链守卫只查**链接字面量**（`http(s)://` / `mailto:`），所以不误报。
